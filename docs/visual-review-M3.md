# M2／M3 視覺測試紀錄

日期：2026-10-27。執行：`pnpm e2e`（Playwright 1.64.1；kiosk／web-blocked 用 Chromium headless shell，notify 用新版 headless Chromium），
截圖在 `test-results/visual/`。範圍：門店後台全部頁面（390×844 與 360×640）、面板與人員手機配對畫面、M2 顧客通知畫面。
每張截圖由 AI 逐張開圖檢查；發現的問題修正後重跑全部 E2E（32 個情境全過），並把能量測的問題寫成 E2E 斷言避免回歸。

## 環境與命名

| 對象 | Viewport | 截圖前綴 |
|---|---|---|
| 門店後台 | 390×844（DPR 2、觸控、Android UA） | `store-*`；比視窗長的頁面另存 `*-full`（整頁截圖中 `position: fixed` 的底部列會出現在中段，屬截圖產物，以視窗截圖為準） |
| 門店後台 | 360×640 | `small-store-*` |

字型：Noto Sans CJK TC，全部截圖**沒有方塊字**。

## 每頁自動量測（`layoutIssues()`）

所有門店後台頁面、M2 號碼頁／轉交碼頁、配對頁皆斷言：`scrollWidth ≤ 視窗寬`（無水平捲動）、所有 `button／a／select／input／[role=switch]／[role=radio]／含勾選框的 label` ≥ 44×44。

## 人工檢查項目（每張都看）

溢出、文字截斷與孤字斷行、對比、觸控目標、中文字型、表單錯誤提示是否可見且標在對的欄位、空狀態、載入／讀取失敗狀態、提示訊息是否遮住內容。

## 本機做不到、未驗證（不代表通過）

- **真實推播服務**：FCM（Android Chrome）、APNs（iOS 16.4+ 主畫面 app）實際送達、鎖屏通知樣式；本機以假推播端點＋CDP 投遞驗證。
- **iOS Safari／WebKit**：本機只有 Chromium（以 UA 模擬）；「分享 → 加入主畫面」流程、主畫面 app 與 Safari storage 分離、安全區需實機。
- **震動與聲音**：只驗證程式有呼叫 `vibrate` 與 Web Audio；實際手感與音量需實機。
- **廣告**：R2 自訂網域（CORS、Cache-Control）、面板 Service Worker 跨網域快取、拔網路線續播需 staging／實機。
- **像素基準比對**：仍以量測斷言＋人工檢查代替。
