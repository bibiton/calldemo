## 每頁自動量測

- `layoutIssues()`：`scrollWidth ≤ 視窗寬`（無水平捲動）；所有按鈕／連結／輸入／開關 ≥ 44×44。
- `textIssues()`（M4 新增）：畫面文字不得出現 `NaN`、`undefined`、`Infinity`、`[object Object]`、`null`（數字格式化失敗的痕跡）。
- 顧客圖片：首屏量測（號碼、前面幾位、提醒卡、送出鈕在首屏）、輪播位置與 3:2 比例、**破圖偵測**（可見但 `naturalWidth = 0` 的圖片數必須為 0）、叫號提醒以 `elementFromPoint` 確認蓋過輪播。

## 人工檢查項目（每張都看）

溢出、截斷與孤字斷行、對比、觸控目標、中文字型、空／載入／錯誤狀態、表格在手機上的呈現（一律卡片化）、數字格式（金額、MB、千分位）、錯誤提示位置。

## 本機做不到、未驗證（不代表通過）

- **Cloudflare Access 實際登入**（One-time PIN 信箱驗證碼、登出、JWT 過期後的導向）：本機以繞過旗標＋測試產生的 RSA 金鑰驗證。
- **Analytics Engine 實際資料**（今日 API 請求、每日匯入、夜間喚醒點）：本機以 mock binding 與假 SQL API 驗證。
- **R2 自訂網域 `call-media.jjoy.ai` 圖片**（CORS、快取、iOS Safari 的 lazy 載入）：本機由面板 dev server 提供。
- **iOS Safari／WebKit 實機**、**實際電視 1080×1920**：同 M3。
- **像素基準比對**：仍以量測斷言＋人工檢查代替（版面持續調整中）；本次回歸以與 M3 截圖的像素差異挑出要人工檢查的畫面。
